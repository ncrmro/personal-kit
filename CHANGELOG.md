# Changelog

All notable changes to Persona Kit will be documented in this file.

## [0.1.0] - 2024-11-16

### Changed
- **Major Rewrite**: Transformed from Spec Kit to Persona Kit
- Complete overhaul of the project purpose and functionality
- New focus on markdown-based persona creation and management

### Added
- `persona-kit init` command to initialize new projects
- `persona-kit persona create` command to create new personas
- `persona-kit persona list` command to list available personas
- `persona-kit review` command for website reviews
- `persona-kit check` command to verify installation
- Example persona template
- Project directory structure (.personas/, .reviews/)

### Removed
- All spec-driven development commands
- Spec-related templates and workflows
